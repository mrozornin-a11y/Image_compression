# Сортировка и сжатие изображений

Небольшая настольная программа для Windows 11 (Python + PySide6 + Pillow).
Она отбирает фотографии по имени и сохраняет их сжатую копию в новую папку,
сохраняя структуру вложенных папок. Исходные файлы не изменяются.

## Запуск

1. Установите Python 3.11–3.13 с [python.org](https://www.python.org/downloads/)
   (при установке отметьте «Add python.exe to PATH»).
2. Дважды щёлкните `run.bat` в папке проекта.

При первом запуске `run.bat` создаёт виртуальное окружение `.venv` и устанавливает
зависимости из `requirements.txt` (нужен интернет, несколько минут). Следующие запуски
происходят сразу.

Ручной запуск:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

## Работа с программой

1. **Выбрать исходную папку** — программа сканирует все вложенные папки.
2. Выбрать режим отбора:
   - **Вариант А** — имена вида `93. Г 144 скрещенные.jpg` (регулярное выражение `^\d+\.\s+`);
   - **Вариант Б** — все остальные имена (`4_Г 144_отраж_5х.jpg`, `образец_27.tif`).
3. Просмотреть дерево отобранных изображений (размер, разрешение, DPI) и предпросмотр.
   При необходимости поправить список вручную:
   - **Убрать из списка** (кнопка, клавиша Delete или контекстное меню) — выделенные
     изображения или все изображения выделенной папки не будут сжиматься;
   - **Добавить из этой папки…** (кнопка, Insert или контекстное меню) — открывает список
     изображений той же подпапки, которых нет в списке, и позволяет отметить нужные.

   Добавленные вручную файлы показаны курсивом. При смене режима отбора ручные
   изменения сбрасываются (программа предупреждает об этом).
4. **Выбрать выходную папку** (она не может совпадать с исходной или находиться внутри неё).
5. Выбрать качество JPEG (95 / 92 / 90) и нажать **Начать обработку**.

В выходной папке создаётся та же структура папок со всеми файлами. Изображения из
списка сжимаются; изображения вне списка (исключённые фильтром или убранные вручную)
и прочие файлы копируются без изменений. Если файлы с такими именами уже есть, программа спросит,
перезаписать ли их.

## Как сжимаются файлы

Разрешение, имена и расширения не меняются; фильтры не применяются.
Сохраняются ICC-профиль, EXIF, DPI и другие метаданные, которые поддерживает Pillow.

| Формат | Способ |
|---|---|
| JPEG / JPG | пересжатие с выбранным качеством, `optimize=True`, исходная цветовая субдискретизация |
| PNG | только без потерь (`optimize=True`), без смены режима и палитризации |
| TIFF / TIF | только без потерь (Deflate), все страницы, исходная глубина цвета и каналы |
| WEBP | lossless-файлы — без потерь, остальные — с выбранным высоким качеством |
| BMP | копируется без изменений |

Для форматов без потерь результат повторно открывается и попиксельно сравнивается
с оригиналом. Оригинал копируется без изменений, если:

- сжатый файл получился не меньше исходного;
- сохранность данных нельзя гарантировать (16-битный цветной PNG, TIFF с нестандартной
  глубиной цвета, анимированный PNG/WEBP и т. п.);
- файл не удалось прочитать (это отмечается в журнале как ошибка).

## Проверка

```bash
python -m unittest discover -s tests -v
```

Тесты создают набор с вложенными папками, кириллическими именами, расширениями в разном
регистре и всеми поддерживаемыми форматами. Они проверяют фильтрацию в обоих режимах,
структуру папок, неизменность исходной папки, размеры в пикселях, побайтовое копирование
прочих файлов, попиксельную сохранность форматов без потерь, отмену и подсчёт экономии.
